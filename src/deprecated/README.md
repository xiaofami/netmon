# 已停用模块

2026-11-07 起以下功能从产品中移除，源码保留以便日后恢复，**不参与任何构建目标**：

| 文件 | 原功能 | 停用原因 |
|---|---|---|
| `apps.*` | 服务类别推测、遥测域名识别 | 只靠域名关键词/端口，准确率低，参考价值有限 |
| `probe.*` | ping / HTTP 线路质量主动探测 | 探测口径容易误导，且增加额外出站流量 |
| `reach.*` | 直连 vs 代理可达性探测、加规则建议 | 判定依赖 HTTP 状态码，误报多，用户反馈没用 |
| `test_probe.c` | probe 单测 | 随 probe 一起停用 |

数据库里的 `probe` / `reach` 历史表保留未删，但不再写入。
恢复方法：把文件移回 `src/`，在 `Makefile` 的 `NETMON_SRC` / `REPORT_SRC` 加回去，
并恢复 `netmon.c` 的调度与 `netmon-report.c` 的相应输出段。
